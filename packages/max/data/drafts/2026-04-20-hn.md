TITLE: Show HN: PromptFuel – Token Optimization Toolkit for LLM Apps

I built PromptFuel because I got tired of manually auditing prompts to cut costs. Started as a CLI tool, now it's a full toolkit: CLI, Chrome extension, MCP server for Claude Code, and an npm SDK.

**The core problem:** LLM costs balloon when you're iterating. A 5% improvement in prompt efficiency compounds across thousands of requests. Token counters exist, but they're isolated—you can't correlate usage patterns, compare models, or get actionable suggestions without stitching together three separate tools.

**What makes it interesting technically:**

The core package has **zero runtime dependencies**—just pure TypeScript. Supports 23 models across OpenAI, Anthropic, and Google, with dynamic tokenizer switching based on model. Built a minimal cost calculator that handles variable pricing (GPT-4o turbo vs. standard, etc.).

Monorepo structure: the CLI uses Ink for TUI, the extension is DOM-based (not React, smaller), and the MCP server speaks stdio transport. All building blocks are composable—if you only want the tokenizer, install the npm SDK. If you want the full workflow, use the CLI.

**The honest part:** Currently 0 GitHub stars, but the approach is solid. I've been dogfooding it across real projects. Open source and MIT licensed.
